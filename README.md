# My first Unity Project - Speedy

## Status of the project
finished

## Goal
The goal of this project was to become familiar with the basics of Unity and to create a small project from start to finish.

I wanted to learn how to:
- Set up a Unity project and connect it to GitHub
- Spawn and destroy GameObjects
- Move an object using physics
- Modify movement during runtime
- Display runtime values through the UI

## What does the programm do?
The project spawns a small character that continuously moves from the left side to the right side of the screen.

When the character reaches the right side, it is destroyed and a new instance is spawned on the left side, creating a continuous movement loop.

The project also includes a slider that allows the player to change the character's velocity at runtime. The current velocity is displayed on the screen.

## Challenges
As this was my first Unity project, most of the challenges were related to getting familiar with the Unity editor and its workflow.

One of the main things I wanted to understand was how to use a Rigidbody for movement, even though the character only moves in one direction. This helped me get my first practical experience with Unity's physics system.

I also encountered a UI layout problem. The text element displaying the velocity was larger than necessary and overlapped with the slider. As a result, part of the slider could not be used. Fixing this helped me understand how Unity's UI elements and their layouts interact.

## What did I learn?
This project gave me my first practical experience with:
- Basic GameObjects and their interactions
- Object spawning and destruction
- Rigidbody-based movement
- Runtime interaction through UI elements
- Displaying changing values in the UI
- Using GitHub with a Unity project
- Creating my first game assets with Aseprite
  
Most importantly, I learned how the different parts of a Unity project come together in a working application.
